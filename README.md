# 神託の迷宮（仮）

プレイヤーは忘れられた小神。パーティを直接は動かさず、戒律（事前の方針）と神託（戦闘中の短い指示）だけで冒険に関わるオートバトルRPGの企画と試作。

## 中身

| パス | 内容 |
|---|---|
| `prototype/shintaku.html` | 遊べる戦闘試作。リアルタイム戦闘・神託・連携技・閃き・書物・師弟・装備・職と上級職・アビリティ・流儀・人間関係と離反 |
| `mock/ff6mock.html` | 見た目のモック（SNES相当 256×224）。シームレスな冒険画面・世界地図・拠点・技能 |

どちらも1ファイルで完結したHTMLです。ブラウザで開けば動きます（フォントだけGoogle Fontsから読み込みます）。
試作の進行状況はブラウザの localStorage に保存されます。

## 設計の柱

- **神の立場**：戒律で方針を決め、神託は届くまで約1秒かかる。従うか、どう受け取るかはリーダーの性格と信仰次第
- **ロストあり**：倒れて10秒以内に救えなければ戻らない。全員に固有の背景と願いがある
- **コンボを覚えさせる**：複数人の連携技と、一人の技の組み合わせで発動する流儀の二層
- **技の覚え方**：書物（確実・体得には開眼が必要）、閃き（強敵ほど・神託の直後ほど起きやすい）、師弟（閃いた技は口伝でしか継げない）
- **職とアビリティ**：上級職でしか閃けない技がある。アビリティは職の修行で覚え、どの職にも持ち越せる（FF5方式）
- **人間関係**：忠誠（仲間へ）と信仰（神へ）の二軸。両方が下がると大神の使徒に誘われて離反し、敵として現れる
- **世界**：地方を「区画」でつなぎ、歩く・戦う・移動をシームレスに（クロノ・トリガー／FF12方式）。拠点はどの町にも置ける
